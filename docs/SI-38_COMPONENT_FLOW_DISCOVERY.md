2. Preserve the separate public, intentionally server-processed, protected-compartment and third-party-processed classifications. Server-held keys and TLS do not justify an E2EE-content claim. Record the authorized purpose and actual processing provider for every plaintext transfer before activation.
3. Integrate and reverify existing SI-35/SI-36/SI-37 work under its authorized PRs. The source observed here has unconditional S3 writes, default redirect behavior, raw S3 diagnostic text and an unbounded scanner response parser. PR48 is separate unfinished work; source visibility is not merge or deployment proof.
4. Webhook destination validation resolves DNS separately from fetch. Review and implement address-bound transport/egress enforcement against rebinding, verify metadata minimization. Categorical persisted/rethrown transport errors are now implemented and tested in PR49; actual address binding remains unfinished. Existing DNS checks alone do not prove the actual connected address. No production-safe egress claim is made.
5. Complete database-backed tenant/role/reveal concurrency tests, request expiry/revocation checks, provider access control, scanner efficacy, artifact provenance, backup/restore, key custody/versioning/rotation and platform integration evidence. Isolated crypto tests cannot substitute for these.

## Continuation and evidence

The inspected API advertises OpenAPI 3.1 and API version 1.0.0, while the package is on the 1.0.0-rc.9 release line. These are different identifiers. The service API represents a client/organization/permission set; no person-specific delegation may be inferred from that credential. API authentication code permits nullable expiry, so downstream integrations must not invent a token TTL or audience claim.

The protected-data and webhook envelope changes have 45 focused tests plus local TypeScript checking. Full CI and broader scope remain separate. Preserve the draft PR and canonical pending statuses until remaining implementation and exact-source verification are finished. The original upstream pin and existing profile decisions are unchanged.
